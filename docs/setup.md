# 初回の準備（約3分）

macOS では集中モードの作成とショートカットの登録をコマンドから行えないため、ここだけ手で設定します。
画面の文言は macOS のバージョンで少し違うことがあります（macOS 26 で想定）。

## 手順1: 集中モード「Zoom中」を作る

1. **システム設定 → 集中モード** を開く
2. 右下の **「集中モードを追加…」→「カスタム」** を選ぶ
3. 名前を **`Zoom中`** にして、好きなアイコンを選ぶ
4. **通知** の項目で、**「指定したアプリからの通知を消音」**（Silence notifications from）を選ぶ
   - 「許可」側を選ぶと、指定したアプリ以外が全部止まるので注意
5. 消音するアプリとして、次を追加する
   - `Claude`（複製したアカウント別の Claude アプリがあれば、それも全部）
   - CLI の Claude Code の通知も止めたい場合は、使っているターミナル（ターミナル・iTerm2・Ghostty など）
   - ついでに止めたいアプリ（Slack など）があれば、ここに足す
6. 必要なら **「デバイス間で共有」** をオフにする（オンのままだと iPhone も一緒に集中モードになる）

## 手順2: ショートカットを2つ作る

**ショートカット** App を開いて、次の2つを作ります。名前は1文字も違えずに入れてください。

### `Zoom中オン`

1. 右上の **＋** で新規ショートカットを作る
2. 右側の検索で **「集中モードを設定」** を探して追加する
3. アクションの文言を **「Zoom中」を「オン」にする**（期間は「オフにするまで」）に変える
4. 上部の名前を **`Zoom中オン`** にする

### `Zoom中オフ`

1. 同じように新規作成して **「集中モードを設定」** を追加する
2. **「Zoom中」を「オフ」にする** に変える
3. 名前を **`Zoom中オフ`** にする

## 手順3: 確かめる

```bash
~/zoom-quiet/bin/zoom-quiet doctor   # ショートカットが2つとも ✓ になるか
~/zoom-quiet/bin/zoom-quiet on       # メニューバーに集中モードのアイコンが出るか
~/zoom-quiet/bin/zoom-quiet off      # アイコンが消えるか
```

初回の `on` / `off` では「ショートカットが集中モードを変更することを許可しますか」のような確認が出ることがあります。許可してください。

問題なければ `zoom-quiet install` で自動起動を有効にします。

## 名前を変えたいとき

ショートカットの名前を変えた場合は `~/.config/zoom-quiet/config` の `ON_SHORTCUT` / `OFF_SHORTCUT` を合わせてください。
